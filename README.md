# PROG5121 Part 2 – QuickChat

## Description
QuickChat is a Java messaging application developed for the PROG5121 Part 2 assignment. The program allows users to log in, send messages, and store messages in a JSON file.

## Features
- User login before accessing the messaging menu.
- Send messages to recipients.
- Validate recipient cellphone numbers.
- Validate message length.
- Generate a unique message ID for each message.
- Generate a message hash.
- Store messages in a JSON file.
- Display "Coming Soon." when the user selects the option to show recently sent messages.
- Exit the application using the menu.

## Technologies Used
- Java
- Apache Maven
- JUnit
- NetBeans IDE

## How to Run
1. Clone or download this repository.
2. Open the project in NetBeans.
3. Allow Maven to load the project dependencies.
4. Build and run the project.
5. Log in and follow the menu instructions.

## Menu Options
1. Send Messages
2. Show Recently Sent Messages
3. Quit

## Message Storage
Messages are saved in `messages.json` in the project directory.

## Testing
JUnit tests are included in the project to test message-related functionality.
